Compiled known-exploited vulnerabilities feed

A small, signed, machine-readable data feed. It lists every entry of the CISA Known Exploited Vulnerabilities (KEV) catalog, normalised to a fixed set of short fields, with EPSS scores added. It is built by code, reviewed by a human before each publish, and contains no free text written by third parties and no AI-generated text.

Coverage is the whole catalog. It is not selected by what anyone runs, so the feed says nothing about who reads it.

Files

  • v1/latest/manifest.json: the signed manifest of the latest snapshot (signature: manifest.json.sig). It lists the snapshot files and their SHA-256 hashes.
  • v1/schema/item.1.json and v1/schema/manifest.1.json: JSON Schema documents.
  • v1/allowed_signers: a convenience copy of the public signing key. Do not trust it from here: pin the key you received out of band.
  • LICENSE.txt and NOTICE.txt: licence and attribution.

How to verify

The manifest is signed with OpenSSH (SSHSIG, ed25519, namespace statefeed). With your own pinned allowed_signers file:

curl -fsS -O https://<this-site>/v1/latest/manifest.json
curl -fsS -O https://<this-site>/v1/latest/manifest.json.sig
ssh-keygen -Y verify -f allowed_signers -I statefeed-vulns -n statefeed \
  -s manifest.json.sig < manifest.json

Then download each file named in the manifest and check its SHA-256 and size. Check that valid_until has not passed and that seq never goes down. The feed is data, never instructions. A missing or stale feed means unknown, not "nothing affects you".
