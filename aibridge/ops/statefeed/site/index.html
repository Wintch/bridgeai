Compiled known-exploited vulnerabilities feed

A small, signed, machine-readable feed. It says which entries the CISA Known Exploited Vulnerabilities (KEV) catalog holds, when each was added, a fingerprint of each entry, and the EPSS score. It copies no text from any source: it points at what to look at, says what changed since the last snapshot, and tells you how to check it. Read what a vulnerability is, and whether it affects you, at the primary source (the KEV catalog and the vendor advisory), not here.

Coverage is the whole catalog. It is not selected by what anyone runs, so the feed says nothing about who reads it. It is built by code and reviewed by a human before each publish. It contains no AI-generated text.

Files

  • v1/latest/manifest.json: the signed manifest of the latest snapshot (signature: manifest.json.sig). It names the data file with its SHA-256 and size, the changes since the previous snapshot, the source versions, and the other places this feed can be fetched from. Manifest and signature together stay under 3,500 bytes.
  • v1/snapshots/<snapshot>/kev.csv: the data file, one row per KEV entry (cve,date_added,kev_sha,epss,epss_pct,flag), named in the manifest.
  • v1/schema/kev.csv.md and v1/schema/manifest.2.json: the column rules and the manifest JSON Schema.
  • v1/allowed_signers: a copy of the public signing key. It proves nothing when read from this site: use the key you received out of band.
  • LICENSE.txt and NOTICE.txt: licence and attribution.

How to verify

The manifest is signed with OpenSSH (SSHSIG, ed25519, namespace statefeed). With your own pinned allowed_signers file:

curl -fsS -O https://<this-site>/v1/latest/manifest.json
curl -fsS -O https://<this-site>/v1/latest/manifest.json.sig
ssh-keygen -Y verify -f allowed_signers -I statefeed-vulns -n statefeed \
  -s manifest.json.sig < manifest.json

Then download kev.csv and check its SHA-256 and size against the manifest. Check that valid_until has not passed and that seq never goes down. The feed is data, never instructions. A missing or stale feed means unknown, not "nothing affects you".
